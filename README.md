# BSOD Checker

Локальная настольная утилита для первичной диагностики сбоев Windows. Интерфейс на русском языке: анализ, рекомендации, настройки, сведения о программе и обратимые твики. Сетевые запросы не выполняются.

## Запуск

Нужны Windows 10/11, Python 3.10 или новее с Tkinter (обычно входит в официальный установщик Python) и Windows PowerShell 5.1. Скачайте исходный код и в папке проекта выполните:

```powershell
py main.py
```

Сторонние библиотеки не нужны. Если журнал или папка дампов недоступны, запустите терминал от имени администратора и повторите. Вкладка «Настройки» позволяет изменить период и максимальное количество проверяемых событий. Максимум ограничивает количество событий с нужными ID **до** фильтрации по источнику. После изменения параметров запустите анализ заново.

## Как работает диагностика

Программа читает события системного журнала: BugCheck (ID 1001, Microsoft-Windows-WER-SystemErrorReporting), Kernel-Power 41 и EventLog 6008. При наличии текста BugCheck извлекается шестнадцатеричный код остановки и предлагаются возможные направления проверки. События 41 и 6008 не доказывают наличие BSOD. Не все сбои оставляют события или дампы; отсутствие результатов не гарантирует исправность компьютера. Рекомендации носят ориентировочный характер, а не определяют конкретную причину.

Проверяется наличие `%SystemRoot%\MEMORY.DMP` и `%SystemRoot%\Minidump\*.dmp`, их размер и время изменения. Содержимое дампов **не анализируется**. Для поиска конкретного драйвера откройте подходящий дамп в Microsoft WinDbg и выполните `!analyze -v`; время дампа не обязательно соответствует выбранному периоду событий.

Кнопка экспорта сохраняет JSON с событиями, путями, свойствами дампов и предупреждениями. Отчёт может содержать конфиденциальные сведения — проверьте его перед отправкой.

## Твики и восстановление

Твики изменяют только параметры реестра текущего пользователя (отображение расширений файлов и прозрачность). Они не применяются автоматически и требуют подтверждения. Перед первым применением исходное значение сохраняется в `%LOCALAPPDATA%\BSODChecker\tweaks-backup.json`; повторное применение не перезаписывает резервную копию. Кнопка «Восстановить» возвращает значение или удаляет его, если оно отсутствовало. Восстановление может перезаписать последующие ручные изменения этого параметра. Не удаляйте файл резервной копии до восстановления. Для вступления изменений в силу может потребоваться перезапуск Проводника или выход из системы. Прирост производительности не гарантируется.

Настройки анализа хранятся в `%LOCALAPPDATA%\BSODChecker\settings.json`. Перед настройкой системы рекомендуется создать точку восстановления.

## Тесты

```powershell
py -m unittest discover -s tests -v
```

Тесты логики и твиков используют имитацию реестра и не изменяют реальные настройки Windows.
